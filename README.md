# 🏙️ Мои места в Петербурге

Интерактивное приложение-карта для отметки мест в Санкт-Петербурге с привязкой видео из вашего влога.

## 🚀 Быстрый старт

### 1. Установите зависимости
```bash
npm install
```

### 2. Запустите для разработки
```bash
npm run dev
```
Откройте http://localhost:5173 в браузере.

### 3. Соберите для продакшена
```bash
npm run build
```
Готовые файлы будут в папке `dist/`.

---

## 📱 Как установить как приложение на телефон

### На iPhone (Safari):
1. Откройте сайт в Safari
2. Нажмите кнопку «Поделиться» (квадрат со стрелкой)
3. Прокрутите вниз и нажмите «На экран Домой»
4. Нажмите «Добавить»

### На Android (Chrome):
1. Откройте сайт в Chrome
2. Нажмите меню (⋮) в правом верхнем углу
3. Выберите «Добавить на главный экран»
4. Нажмите «Добавить»

После установки приложение будет работать как нативное — с иконкой на рабочем столе и полноэкранным режимом.

## 🌐 Как опубликовать в интернете (бесплатно)

### Вариант 1: Vercel (рекомендуется)
```bash
npm install -g vercel
vercel
```
Следуйте инструкциям. Через минуту получите ссылку вида `https://your-app.vercel.app`.

### Вариант 2: Netlify
```bash
npm install -g netlify-cli
npm run build
netlify deploy --prod --dir=dist
```

### Вариант 3: GitHub Pages
1. Запушьте код в репозиторий на GitHub
2. В настройках репозитория → Pages → выберите ветку `main` и папку `/dist`
3. Сайт будет доступен по адресу `https://username.github.io/repo-name`

### Вариант 4: Cloudflare Pages
1. Подключите репозиторий на dash.cloudflare.com
2. Настройте сборку: `npm run build`, директория `dist`
3. Получите бесплатный домен `.pages.dev`

## 🎬 Как добавить свои видео

В файле `src/data.ts` замените примерные данные на свои:

```typescript
{
  id: '1',
  name: 'Название места',
  description: 'Описание',
  lat: 59.9398,       // широта
  lng: 30.3146,       // долгота
  category: 'museum', // категория
  videoUrl: 'https://youtube.com/watch?v=ВАШ_ID',
  videoTitle: 'Название вашего видео',
  visited: true,
  visitDate: '2024-03-15',
  notes: 'Ваши заметки',
}
```

Координаты можно узнать:
- Кликнув правой кнопкой на Google Maps → «Что здесь?»
- Или прямо в приложении — нажмите «+» и кликните на карту

## 📂 Структура проекта

```
├── src/
│   ├── App.tsx              # Главный компонент
│   ├── main.tsx             # Точка входа + PWA
│   ├── index.css            # Стили
│   ├── types.ts             # Типы и константы
│   ├── data.ts              # Начальные данные (ваши места)
│   └── components/
│       ├── MapComponent.tsx  # Карта (Leaflet)
│       ├── Sidebar.tsx       # Боковая панель со списком
│       ├── PlaceDetail.tsx   # Карточка места
│       └── PlaceForm.tsx     # Форма добавления/редактирования
├── public/
│   ├── manifest.json         # PWA манифест
│   ├── sw.js                 # Service Worker
│   └── icon.svg              # Иконка
└── package.json
```

## ⚙️ Технологии

- **React 18** + **TypeScript**
- **Vite** — быстрая сборка
- **Tailwind CSS** — стили
- **Framer Motion** — анимации
- **Leaflet** — карта (бесплатная, без API-ключей!)
- **LocalStorage** — хранение данных в браузере
